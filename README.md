# CHRONOBREAK — When Speed Breaks Time

> *Speed is not how fast you move. It's how slowly the world moves around you.*

A 24-second procedural Blender film for the RenderJuice Blender Animation & Programmatic Rendering Contest 2026 (theme: **SPEED**). An amber pulse accelerates through a skeleton-clock universe while the world around it slows, fractures and freezes. Then the camera rises to reveal that the pulse's whole journey traced the clock's **second hand**.

Everything in the scene (gears, gear trains, shards, motion, camera, lights, materials, compositing) is generated by the Python in `scripts/` from two JSON files in `config/`.

## Prerequisites

| Tool | Version used | Notes |
|---|---|---|
| Blender | 5.2.0 LTS | path set in `config/render.json` → `blender_exe`, or env var `BLENDER` |
| Python | 3.11 (system) | for tests, encoding, verification |
| NumPy, pytest, imageio-ffmpeg | see `requirements.txt` | `pip install -r requirements.txt` |
| FFmpeg | 7.1 (bundled by `imageio-ffmpeg`) | a system `ffmpeg` on PATH is used first if present |

Blender's bundled Python already includes NumPy. No GPU is required: Eevee runs on integrated graphics (developed on Intel UHD Graphics with an i7-1355U).

## One-command usage

```
python run.py build      # regenerate output/chronobreak.blend (~5 s)
python run.py test       # pytest: math, determinism, frame bounds, Blender scene integrity
python run.py stills     # stage 1: QA stills + contact sheet
python run.py animatic   # stage 2: full 640x360 animatic + MP4
python run.py benchmark  # stage 3: 1080p benchmark frames
python run.py final      # stage 4: 576 frames at 1920x1080 (resumable)
python run.py encode     # stage 5: output/CHRONOBREAK.mp4 (H.264, yuv420p, CRF 16)
python run.py verify     # frames + ffmpeg probe/decode + SHA-256 -> output/evidence/verification.json
python run.py evidence   # contact sheet + frame-difference scan + genuine Blender UI screenshot
python run.py all
```

## Layout

```
config/      scene.json (timing, path, clock, seeds), render.json (presets, paths, encode)
scripts/     animation_math.py, procedural.py  (pure NumPy, unit-tested)
             build_scene.py → create_materials / create_clockwork / create_pulse /
             generate_fragments / animate_cameras / setup_lighting / setup_compositor
             render_preview.py, render_final.py, encode_video.py, verify_output.py, capture_evidence.py,
             scan_frames.py
tests/       pytest suites
docs/        SHOT_LIST, TECHNICAL_WORKFLOW, RENDER_BENCHMARK, QA_REPORT, SUBMISSION
output/      chronobreak.blend, CHRONOBREAK.mp4, frames/, previews/, evidence/
```

See `docs/TECHNICAL_WORKFLOW.md` for the mathematics and `docs/SHOT_LIST.md` for the beat sheet.
